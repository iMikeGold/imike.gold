# Distribution feeds

Add final footage here:

- `manchild/preview.mp4`
- `works/preview.mp4`
- `system/preview.mp4`

Optional posters:

- `manchild/poster.webp`
- `works/poster.webp`
- `system/poster.webp`

Then add the matching `videoSrc` and optional `posterSrc` values in
`src/config/gateway.ts`.

Feeds remain paused until their cabinet is hovered, focused or selected.
