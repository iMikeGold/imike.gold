# imike.gold

## BillBoard OS

The gateway surface for the Mike Gold world.

Three entry points. One viewport. No conventional portfolio front page.

- **Meet the Manchild** → `mikegold.co.uk`
- **Enter the System** → `imikegold.com`
- **Explore the Works** → `houseofgold.online`

The interface is designed to operate in standby before its moving media is
connected. See `docs/BILLBOARD_OS.md`.
